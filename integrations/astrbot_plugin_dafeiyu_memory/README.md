# 大肥鱼共享记忆（AstrBot 插件）

让 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 上的大肥鱼和桌宠共用同一个文件夹里的人格、记忆、聊天记录和见面状态：在 QQ 上告诉她的事，桌宠上的她也知道，反过来也一样。

桌宠不需要这个插件也能完整使用；只有想把聊天软件里的她和桌宠连起来时才装。

## 先准备好共享文件夹

1. 在桌宠里打开「AI 设置 → 人格和记忆存在哪」，选「存在我选的文件夹里」，选一个文件夹（通常放在会自动同步的网盘里）。桌宠会在里面建好 `人设.md`、`记忆.json`、`聊天记录.json`、`陪伴状态.json`。
2. 让 AstrBot 所在的机器也能看到这个文件夹：
   - AstrBot 和桌宠在同一台电脑上：直接用这个文件夹的路径；
   - AstrBot 在另一台电脑或服务器上：在那台机器上装同一个网盘的同步客户端，或者用别的方式把文件夹同步过去；
   - AstrBot 跑在 Docker 里：把这个文件夹挂载进容器，下面填的要是**容器里的路径**。

插件不会自己从零建这些文件：文件夹里还没有 `记忆.json`（桌宠还没选这个文件夹，或者网盘还没同步好）时，它只读不写，免得同步到一半时多出一份空的。

## 安装

1. 把整个 `astrbot_plugin_dafeiyu_memory` 文件夹复制到 AstrBot 数据目录下的 `data/plugins/` 里（Docker 部署一般是容器里的 `/AstrBot/data/plugins/`），文件夹名保持不变。最后应该是 `data/plugins/astrbot_plugin_dafeiyu_memory/main.py` 这样的结构。
2. 重启 AstrBot，或者在管理面板的插件页面重载插件。
3. 在管理面板的插件页面找到「大肥鱼共享记忆」，打开它的配置，填下面几项。

插件只用到 Python 自带的库，没有 `requirements.txt` 要装。`metadata.yaml` 里的 `name`、`desc`、`version`、`author` 是 AstrBot 必须要的；`repo` 只是指向本项目的仓库，可以不填。

**更新插件**：重新复制一遍文件夹再重载。AstrBot 面板里的在线「更新」用不了：`repo` 指的是整个桌宠项目，不是单独的插件仓库。

## 配置项

| 配置 | 填什么 |
| --- | --- |
| `shared_dir` 共享文件夹的路径 | AstrBot 那台机器上看到的共享文件夹路径（和桌宠选的是同一个文件夹）。留空时插件不读写任何文件。 |
| `owner_ids` 主人的账号 ID | 你自己聊天账号的 ID（QQ 号等），可以填多个。只有这些账号**私聊**时，插件才会用上和记下你的事。 |
| `platform_hint` 在聊天软件里额外告诉她的话 | 接在人设后面，告诉她现在是在聊天软件里（不能动、不能看屏幕、不能设提醒、发不了桌宠的表情包）。一般用默认的就行。 |
| `timezone` 时区 | 用来算「今天」、连续见面天数和记录上的时间。填和桌宠那台电脑一样的时区，国内是 `Asia/Shanghai`；AstrBot 跑在国外服务器上时尤其要填对。 |

## 它读什么、写什么

| 文件 | 在所有对话里 | 只在主人私聊时 |
| --- | --- | --- |
| `人设.md` | 读：作为她的人格，加上 `platform_hint`，排在 AstrBot 原来的人格设定前面 | 同左 |
| `记忆.json` | 不读不写 | 读：把记住的事告诉她；写：她回复里用 `<memory>` 标出的新记忆（每次最多 3 条、每条最多 100 字，满 120 条就不再记，请你到桌宠的「AI 设置」里删掉一些旧的），来源记为 `AstrBot` |
| `聊天记录.json` | 不读不写 | 读：最近 12 条在桌宠上的聊天，让她接得上话；写：把这次你说的和她回的追加进去 |
| `陪伴状态.json` | 不读不写 | 读写：今天是不是第一次见、隔了几天没见、刚才是不是在桌宠上见过（文件不存在时不新建，由桌宠创建） |

- 她回复里的 `<memory>` 标记在所有对话里都会被去掉，发出去的消息里看不到。
- 写文件时先写临时文件再替换，读不懂的文件不会被覆盖。
- 注意：装上以后，`人设.md` 会用在这个 AstrBot 的**所有对话**里（包括群聊）。如果你想让聊天软件里的她继续用 AstrBot 自己的人格设定，先别装，或者等以后改成「只共享记忆、不共享人格」的版本。

## 隐私规则

- 只有 `owner_ids` 里的账号、并且是**私聊**时，插件才会读你的记忆、最近的聊天和见面状态，也只有这时才会往文件夹里写东西。
- 群聊里、别人私聊她时，插件只提供人格：不会提起你的事，也不会记下任何内容，即使她在回复里写了 `<memory>` 也会被丢掉。
- `owner_ids` 留空时，任何对话都不会碰记忆和聊天记录。
- 文件夹里的聊天记录也会包含你在桌宠上的聊天，以及她看你屏幕时的点评；共享文件夹放在网盘里时，这些内容会经过网盘同步。
