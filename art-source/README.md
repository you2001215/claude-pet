# 美术原始素材

Claude 装大肥鱼的原始素材，桌宠里用的立绘和动画都是由这些素材处理得到的。**全部为 AI 生成内容**。

| 目录 | 内容 | 怎么来的 |
| --- | --- | --- |
| `立绘/` | 三视图和 11 张动作立绘（绿幕或白底原图） | Google Gemini 生成，提示词见 `立绘提示词.md` |
| `首帧/` | 图生视频用的首帧：16:9 纯绿幕，人物位置和大小按规范摆好 | 由三视图里的立绘合成 |
| `动画/` | 绿幕原始视频：待机、东张西望、原地走路、思考中、说话、睡觉、打哈欠伸懒腰、吃白饭（各 10 秒），挥手打招呼、被摸头、傲娇生气（5 秒），被点开心（20 秒）。挥手和被摸头只用前 5 秒，打哈欠伸懒腰只用前 5.5 秒；被点开心只用 9.5~14.5 秒那一跳（前面有一段会染黄背景的星星边框）；傲娇生气带「豆包AI生成」水印，处理前把左右两侧 300 px 涂成纯绿 | AI 视频工具图生视频 |
| `立绘提示词.md` | 生成立绘用的通用前缀和 13 个动作的提示词 | 本项目编写 |
| `动画提示词.md` | 生成动画用的通用前缀和 18 个动作的提示词 | 本项目编写 |

## 处理流程

- **立绘 → 桌宠里的透明立绘（`assets/pet/`）：** 抠掉白底或绿幕，再按脚底位置对齐。
- **动画 → 桌宠里的透明动画（`assets/claude/`）：** 运行 `python3 tools/process_clip.py 动画/待机.mp4 ../assets/claude/待机.webm`。脚本会抠绿幕、去绿边，按第一帧把人物缩放并对齐到统一位置，输出透明 VP9 视频。
