# 1.6.1 真机验证清单

云端测不到的东西，要在你的电脑上试一下。每项后面写「好了」或者「不对：看到了什么」，最后在右键菜单里点「导出诊断信息…」，把清单和诊断文件一起发给 Claude。

## 先做的准备
1. **备份你现在的数据**：在托盘里点「退出」，然后把整个数据文件夹复制一份到别处。
   - Windows：在资源管理器地址栏输入 `%APPDATA%\ClaudePet`
   - Mac：在访达里按 Cmd+Shift+G，输入 `~/Library/Application Support/ClaudePet`
   1.6.1 能直接读 1.6.0 的数据，只会多出 `.bak` 备份文件，但测试版先备份最稳妥。
2. **拿安装包**：打开 GitHub 仓库 →「Actions」→「测试和打包」里最新一次绿色对勾的运行（分支 `claude/youthful-meitner-17h6uk`）→ 页面最下面的「Artifacts」，下载 `ClaudePet-windows` 或 `ClaudePet-mac-arm64`（要登录 GitHub；每次运行的安装包保留 14 天）。下载下来是一个 zip，解压后才是安装包和 `.sha256` 校验文件。

## Windows（华硕）
- [ ] 安装：双击安装包。如果出现蓝色的「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。装好后她会出现在桌面上。
- [ ] 已经开着时再双击桌面图标：不会出现第二只，也不会多一个托盘图标，她会说一句话。
- [ ] 说话：和她聊一句，能听到 Edge 在线语音（声音比较自然）。
- [ ] 麦克风：在「AI 设置 → 语音」里下载语音识别模型，然后在聊天框点麦克风说一句话，看能不能识别出来。快速连点两下麦克风按钮，不应该报错。
- [ ] 离线语音：同一页下载离线语音模型，把引擎切成离线语音，点「试听」。**如果你的 Windows 用户名是中文**，这一项特别要看：念不出来或者变成机器音，就记下来。
- [ ] 看屏幕（自动）：在设置里把「看屏幕」改成「经常」，打开浏览器正常用 10～20 分钟。她看之前会先冒出「让我偷偷瞄一眼你的屏幕…」，然后点评一句。**留意 360、火绒、Defender 有没有弹窗拦截 PowerShell。**有两块屏幕的话，看她截的是不是浏览器所在的那块。
- [ ] 看屏幕（手动）：右键 →「看看我在看什么」，她会点评。
- [ ] 改提醒：跟她说「五分钟后提醒我开会」，再说「把开会提醒改到十分钟后」。右键菜单的「提醒」里应该只剩新的那一个，到点会响。
- [ ] 记忆：打开「AI 设置」，先别关；去聊天框告诉她一件新的事；回到设置页随便改一项，点「保存」，新记的那条还在。记忆框旁边显示「已记住 N / 120 条」。
- [ ] 动画：盯着待机、走路、说话看几次循环，不应该再闪一下。让她睡着以后点她，能看到她站起来的那段。
- [ ] 换屏幕和任务栏：把她拖到另一块屏幕，再拖回来；改一次显示缩放或者任务栏位置，她应该站在任务栏上面，不会陷进去。
- [ ] 占用：她待机 5 分钟后，打开任务管理器，找名字带 ClaudePet 的几个进程，记下内存和 CPU 的大概数字，Claude 装和女仆装各记一次。
- [ ] 诊断信息：右键 →「导出诊断信息…」，存到桌面，打开看一眼。里面不应该有你的用户名、Key、聊天内容。
- [ ] 开源许可：「AI 设置」拉到最下面，点开「开源组件与许可」，能看到文字。

## Mac（M5）
- [ ] 安装：解压，把 ClaudePet.app 拖进「应用程序」。第一次右键 →「打开」。这次的包是自动签过名的，正常应该能直接打开。如果提示「已损坏」，在终端运行 `xattr -cr /Applications/ClaudePet.app` 后再打开。
- [ ] 说话、麦克风、离线语音：同 Windows。
- [ ] 看屏幕：手动让她看一次。系统会要求你在「系统设置 → 隐私与安全性 → 录屏与系统录音」里允许 ClaudePet，允许后重启桌宠再试。
- [ ] 诊断信息：同 Windows。

## 不用测的
- 画面进程崩溃后自动恢复、断电后数据从备份恢复：已经在云端用自动测试验证过。
